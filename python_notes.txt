========================
1. BASICS
========================
Types (I F S B):
int    → 10
float  → 5.5
str    → "hello"
bool   → True

Example:
a = 10
b = 5.5
c = "bhanu"
d = True
print(type(a), type(b), type(c), type(d))

Input:
input → string → convert → use

Example:
a = float(input("Enter: "))
b = float(input("Enter: "))
print(a + b)


========================
2. OPERATORS
========================
Arithmetic:
+  -  *  /  %  **
Example:
print(10 + 5)
print(10 % 3)
print(2**3)

Comparison:
==  !=  >  <  >=  <=
Example:
print(5 > 3)
print(5 == 5)

Logical:
and  or  not
Example:
print(True and False)
print(True or False)


========================
3. LISTS
========================
List = mutable

Example:
a = [1,2,3]
a.append(4)
print(a)

a.extend([5,6])
print(a)

a.remove(3)
print(a)

Access:
print(a[0])
print(a[0:2])

Nested:
x = [[1,2],[3,4]]
print(x[0][1])


========================
4. TUPLES
========================
Tuple = immutable

Example:
t = (1,2,3)
print(t)

Unpacking:
a = (10,20,30)
x,y,z = a
print(x,y,z)


========================
5. STRINGS
========================
s = "Hello Bhanu"

Access:
print(s[1:4])

Methods:
print(s.lower())
print(s.upper())

Formatting:
name = "Ram"
print(f"Hello {name}")


========================
6. CONDITIONS
========================
Example:
marks = 85

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("C")


========================
7. LOOPS
========================
Example:
for i in range(1,6):
    print(i)

With step:
for i in range(1,10,2):
    print(i)


========================
8. LIST COMPREHENSION
========================
Example:
nums = [1,2,3,4]

even = [x for x in nums if x % 2 == 0]
print(even)

squares = [x*x for x in range(5)]
print(squares)


========================
9. MEMBERSHIP & IDENTITY
========================
Example:
print("a" in "apple")
print("z" not in "apple")

a = 10
b = 10
print(a is b)


========================
10. PROGRAMS
========================

Grade:
marks = 60

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 50:
    print("C")
else:
    print("Fail")


Largest:
A, B, C = 10, 20, 15

if A > B and A > C:
    print("A")
elif B > C:
    print("B")
else:
    print("C")


Vowel:
ch = "a"

if ch in "aeiou":
    print("Vowel")
else:
    print("Consonant")


Sum Pattern:
total = 0
for i in range(1,6):
    total += i

print(total)
